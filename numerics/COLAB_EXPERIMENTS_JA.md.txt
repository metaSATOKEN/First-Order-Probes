# 3実験のColab実行・再開ガイド

統合稿のための**合成データの追加検証**です。実機データは使いません。
実行完了は、新規性・検定の妥当性・一方の手法の優越性の保証ではありません。

## 最短の使い方

1. [1セル用Python](colab/covariance_consistency_one_cell.py)の全文をコピー。
2. 新しいColabの**1個のコードセル**へ貼り付けて実行。
3. **Google Driveへの接続は不要**。初期設定では接続・認証を行いません。
4. 45分で区切られると、`PARTIAL`（途中）のZIPが自動ダウンロードされます。PCに保存してください。
5. **同じランタイムなら、同じセルをそのまま再実行**して再開。全条件が完了すると `COMPLETE` のZIPが自動ダウンロードされます。

または、[1コードセルのノートブック](colab/covariance_consistency_one_cell.ipynb)を
Colabへアップロードしてください。GPUは不要です。Colab標準のNumPy・SciPy・
Matplotlibを使用します。ブラウザがダウンロードを止めた場合は、表示されたZIPを
Colab左側の「ファイル」から手動でダウンロードしてください。
**ランタイムの削除・リセットなどでローカル保存内容を失った場合、最後にPCへ
ダウンロードしたZIP以降の進捗は復元できません。** ノートブックの保存だけでは
計算結果は保存されません。途中ZIPを毎回確保してください。

A100ランタイムでも実行できますが、この実装はCPU側のNumPy/SciPyを使います。
GPUメモリを利用した高速化版ではありません。開始時の小規模セルフチェックは
Colab上で実行し、`colab_self_check.json` に保存します。

## 冒頭の設定

```python
PROFILE = "main"
EXPERIMENTS = (1, 2, 3)
SAVE_TO_DRIVE = False
MAX_MINUTES = 45
AUTO_DOWNLOAD = True
RESTORE_ZIP = ""
```

| 設定 | 意味 |
|---|---|
| `main` | 本実行。参照9,999、正常評価20,000、異常評価5,000、理想端点200,000試行／条件 |
| `pilot` | 全条件の少数試行。計算量・不具合確認用。論文の本結果には使わない |
| `smoke` | 各分岐の代表条件だけの短い確認。1%誤警報率を評価できる試行数ではない |
| `EXPERIMENTS` | 例：`(1,)`で実験1だけ。変更すると別の保存先になる |
| `MAX_MINUTES` | バッチ完了後に区切る時間。`0`なら時間制限なし。集計・ZIP化は別途時間がかかる |
| `SAVE_TO_DRIVE` | 既定 `False`。Driveへ接続せずランタイム内に保存。`True`に明示変更した場合だけDrive認証を要求 |
| `RESTORE_ZIP` | 通常は空。ZIPから再開する場合は `"UPLOAD"` またはZIPのパス |
| `MEMORY_BATCH_SIZE` | 時系列を計算する単位。既定64。長い窓では配列サイズに応じてさらに制限 |
| `BATCH_SIZE` | チェックポイントの単位。既定256。計算用の小分けとは別です |

本実行は146条件、共有参照を含む197タスク、計4,779,949試行です。
大半は軽い端点生成ですが、時系列生成・保存・ZIP化には時間がかかります。
所要時間は予備実行で測定してください。45分の区切りは失敗ではありません。
最初に短い確認をする場合は `smoke` に変更し、確認後 `main` に戻してください。
両者は独立した保存先になります。

## 途中保存と再開

通常のColabの作業ディレクトリ `/content` では、保存先は
`/content/covariance_consistency_runs/main_<設定ハッシュ>/` です。
ZIPはその親フォルダに作成され、PCへの自動ダウンロードを開始します。
実際の保存先はセルの出力でも確認できます。

- バッチごとにNPZとSHA-256を含むJSONを確定保存します。
- 同じ科学的設定なら、検証済みバッチを再利用し、未確定バッチだけ再生成します。
- 乱数はタスク・バッチ開始番号で決まり、停止回数に依存しません。
- seed、バッチサイズ、プロフィール、実験選択、実装の変更は別実行になります。
- 時間制限・保存場所・ダウンロード設定は変更しても科学的設定ハッシュを変えません。
- Python・NumPy・SciPyが変わった場合は停止します。同じ環境へ戻すか、意図的に
  `ALLOW_ENVIRONMENT_CHANGE = True` として、環境履歴に変更を残します。
- チェックサム不一致は停止・報告します。壊れた結果を正常扱いしません。

**同じ実行フォルダへ、2つのノートブックから同時実行しないでください。**
通常の停止ボタンによる中断では、割り込みを受け取れた場合に途中ZIPを作成します。
集計・ZIP化・ダウンロードが終わるまで待ってください。強制終了やランタイムの
即時削除ではZIPを作れないため、最後にダウンロード済みのZIPから再開します。

### ZIPから再開する場合

1. 新しいランタイムなど、**空の保存先**を用意します。
2. 前回と同じコード・科学的設定で、冒頭を `RESTORE_ZIP = "UPLOAD"` にして実行します。
3. PCに保存した最新の `PARTIAL` ZIPを選択します。復元後、そのまま未完了分の計算へ進みます。
4. **次回のセル再実行前に `RESTORE_ZIP = ""` へ戻します。** 同じZIPを毎回取り込み直す必要はありません。

内容の異なる既存ファイルを上書きしません。
危険なZIPパス・シンボリックリンク・設定不一致も拒否します。
今回のDriveなしへの既定値変更では計算エンジン・科学的設定を変更していないため、
直前の同じ `1.0.1` 計算エンジンによるZIPも、環境と科学的設定が一致すれば復元できます。

任意で `SAVE_TO_DRIVE = True` にした場合だけ、Drive認証後に
`MyDrive/CovarianceConsistencyExperiments/` を使います。今回の使い方では不要です。

## 固定した実験条件

### 実験1：有限窓分布

- 連続時間OU入力、時定数0.04秒と0.01秒、厳密な定常状態遷移。
- 理想端点：相関率2・20・200、窓長0.032・0.128・0.512・2.048・8.192秒。
- サンプルモーメント：相関率20、刻み0.004・0.002・0.001秒、窓長0.512・2.048・8.192秒。
- 既知ゼロ平均の生モーメント／標本平均を引いた共分散を別計算。
- 正規閾値／積正規閾値／独立正常記録による経験的閾値を比較。
- 積正規の尺度は既知値と、独立参照の100・500・全試行による推定値を比較。
- サンプル残差を端点式で置換しません。各記録を分散1へ再正規化もしません。

### 実験2：雑音補正

- Appendix Aと同じ離散一次再帰と残差係数。
- 上流共有／下流共有雑音。出力での雑音分散比0・0.1・0.5。
- 基準：窓長2.048秒、共有雑音比0.1、対照長比1。
- 窓長0.512・8.192秒、対照長比0.25・4を一軸ずつ変更。
- 独立読出し雑音比0.1、負相関共有雑音、対照分散0.5倍・1.5倍も追加。
- 同じ対象・対照から無補正／対角のみ／全共分散補正を計算。
- **正しく対応した全補正**の参照分布を判定に使用。
  誤った補正の偏りを専用の閾値で吸収しません。
- 真の共分散に対する誤差、相関計算不能率、負固有値率も報告。

### 実験3：固定校正CRとの比較

- モーメント法は全補正残差の絶対値、CRはクロスフィルタ二乗平均の対照差。
- モーメントは両側、CRは上側。1%・5%の閾値は同じ独立正常記録で決定。
- 閾値決定用と評価用の乱数は独立。真の入力や異常ラベルを検査側へ渡しません。
- CRにも完全な同時2チャネル雑音対照を渡します。生の数値微分は使いません。
- 既存CR構造の**固定校正検査への適用**であって、元論文の推定器の再現ではありません。
- ゲイン±2・5・10%、時定数±2・5・10・20%、遅延±1・2・4サンプル。
- 追加極の時定数比0.1・0.25・0.5、片チャネル私的入力分散比0.02・0.1・0.5。
- 各異常を窓長0.512・2.048・8.192秒で評価。
- 時定数比2・10、相関率2・200、読出し雑音比0.01・0.5は正常とゲイン+5%だけ追加。
- 上流共有入力と時間反転は構造的負例。時間反転は前後余白を含めた全体に適用し、
  中央評価窓のモーメント保存誤差も記録。
- 正常参照の相関率20を固定し、評価入力だけ2・200へ変える正常な分布変化も評価。

全デジタル過程を定常初期状態から生成し、CRは観測記録から20×最大時定数ぶん
ウォームアップします。真の隠れ状態をCRへ与えません。

## 結果の読み方

- 95% Wilson区間は固定参照集合に条件付けた区間です。
- 参照**記録の統計量**の再標本化で、閾値の有限参照不確実性を別表示します。
  時系列ブロックの再標本化ではなく、Wilson区間と合わせた単一の区間でもありません。
- 尺度推定付き積正規閾値は、厳密な既知尺度の検定とは区別します。
- 検出率差は同じ記録の判定差を対応付きで再標本化します。
- 区間は条件ごとのものです。全条件同時95%保証ではありません。
- 名目1%だけを見て勝敗を判断せず、対応する正常条件の**実測誤警報率**を確認します。
- 正常参照記録という追加情報を使っており、任意入力に共通の閾値は保証しません。
- 80%到達窓長は試験グリッド上の観測値で、必要記録長の厳密な保証ではありません。
- 不正定値の強制修正・相関係数のクリップ・失敗試行の無言除外はしません。

## ZIPの内容

| ファイル | 内容 |
|---|---|
| `run_status.json` | COMPLETE / PARTIAL / FAILED、完了条件数 |
| `config.json`, `design.json` | 反復数・全条件・設定ハッシュ |
| `runner_source.py` | 実行セルのソース |
| `environment_history.json` | 環境履歴 |
| `chunks/` | 再開可能な試行統計量、SHA-256 |
| `tables/rejection_rates.csv` | 誤警報・警報・検出率と区間 |
| `tables/covariance_errors.csv` | 補正のバイアス・RMSE・無効率 |
| `tables/paired_comparisons.csv` | 対応付き検出率差 |
| `tables/endpoint_scaling.csv` | 端点予測とサンプル残差 |
| `tables/calibration_uncertainty.csv` | 有限参照による閾値のばらつき |
| `tables/method_timings.csv` | 生成・モーメント計算・CR計算の時間 |
| `tables/record_length_80.csv` | グリッド上の80%検出到達窓長 |
| `tables/coverage.csv` | 完了・未完了条件 |
| `figures/` | 完了範囲のPNG図 |
| `run.log`, `batch_timings.csv` | 進捗と計算時間 |
| `LICENSE*` | コードApache 2.0、研究資料CC BY 4.0 |

生の全時系列は保存せず、各試行の統計量・設定・乱数識別を保存します。
PARTIALでは未完了条件の表や図が存在しない場合があります。
時間比較は単発の壁時計時間で、最適化された実装同士の性能保証ではありません。
