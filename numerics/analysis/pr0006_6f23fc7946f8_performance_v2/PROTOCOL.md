# PR-0006 B25 保存結果分析 v2

解析範囲・条件・比較は[成績閲覧前のv1プロトコル](../../../docs/OMITTED_MATERIALS.md#item-392fef623db8)をそのまま継承する。原データや検出器の訂正版ではない。

v1は全25反復の最終判定ビットまで一致し、最後に外側t区間端点の最大5.704×10⁻¹²差で停止した。[訂正記録](../../../docs/OMITTED_MATERIALS.md#item-0a69fd22f7c4)に原因を保存。Colab SciPy1.16.3とローカル1.17.0のfamily25・df24のt分位点差8.27×10⁻¹¹が原因で、60桁の不完全ベータ関数による別経路照合で確認する。

**集計区間端点の比較だけ**絶対許容差1×10⁻¹⁰を用いる。再推定・閾値はatol=rtol=2×10⁻¹²、最終判定・整数順位・件数は完全一致を維持する。p値・区間族・統計的判定基準を変更せず、区間差で分類が変わっていないことも照合する。旧出力・旧解析ソースを保持し、v2で全原ZIPから再照合する。

補足：この数値差の調査で主要差の一部の数値を見たが、追加の条件・仮説・配分選択は行っていない。報告対象は元カードの全条件のまま。独立確認は元PR-0006の新規データであり、本プロトコル自体を実験前に遡及させない。
