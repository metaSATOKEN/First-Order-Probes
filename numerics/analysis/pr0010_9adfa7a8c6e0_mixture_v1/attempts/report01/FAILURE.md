# 図生成1回目の次元不整合

科学主解析PASS後に報告生成を起動。JSON集計と全表、最初の3図を出力した後、相殺比の図で停止した。

```text
ValueError: x and y must have same first dimension, but have shapes (4,) and (50,)
```

原因：`a['bf'][:,gi,ids,0,:,0]`の複合advanced indexingで用量軸が反復軸より前へ移り、`mean(0)`が反復でなく用量を平均していた。1反復ずつの科学値・JSONの成分計算（配列IDを使わない単一候補索引）は影響しない。同じ書き方のT分解図にも先回りで同じ修正を行う。

修正：`np.take(..., ids, axis=1)`で候補軸を明示してから通常スライスし、50×4×3／6×2の形状をassertする。旧報告ソースと生成済み3図はこのフォルダに保存。主解析コード・カード・原記録・完成反復は変更せず、同じ集計値から図と本文を再生成する。全8図の最終表示点検で反復平均・用量軸を再確認する。
