# Historical scientific and analysis sources

These files retain their original bytes and names from successive experiments. They support inspection and saved-data analysis; this directory is not a single versioned execution environment.

For the current manuscript's PR-0012 confirmation, use the complete [readable FIX1 bundle](../experiments/pr0012_fix1/README.md). Its `sources/` directory contains the correct launcher, runner, and preflight checker together. In this historical directory, `pr0012_launcher.py` and `pr0012_runner.py` are the earlier pre-FIX1 versions. Do not mix this directory into the import path of the FIX1 execution.

The [numerical evidence index](../README.md) links saved reports and their original analysis scripts. Some analysis scripts have dated input/output paths; use a separate working copy before rerunning them.
